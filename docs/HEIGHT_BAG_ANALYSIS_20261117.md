## 4. 原始地面与固定倾斜诊断

每个静止段抽取四帧原始 LiDAR 点云，按启动日志中的外参旋转、平移至 IMU 参考系，再用当时 LIO 姿态转至世界轴方向，拟合下方近水平平面。外参采用已配置的矩阵及平移，不是重新标定出的结果。静止段姿态用于旋转，忽略帧内微小运动；这是辅助诊断，不是独立外部真值。

三段参考点离地距离差约 8.2 mm，支持机体放置高度接近用户描述，但不能代替场地高程真值。

仅使用首段点云确定的固定地面法线 `[-0.00819682, 0.00808741, 0.99993370]`，计算位置变化沿该法线的投影，P1、P2 分别约 +13.49、+16.86 cm。固定倾斜校正后仍约 16.9 cm，因此不像此前 FAST-LIO2 那轮主要是固定世界系倾斜的情况。没有在线应用这个诊断变换，也没有只改 Z 或 TF。

- 不能说完全没有负载抖动，但没有持续掉到 3–5 Hz 或长期输入堆积的证据。单凭本包无法提供整机 CPU 使用率，也不能把这条短暂延迟直接定为高度偏移根因。
